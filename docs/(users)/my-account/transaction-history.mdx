---
title: Transaction History
description: Review account activity and export the current filtered view
---

Open **Portfolio → History** to search, filter, and sort the trades and wallet actions
recorded by the platform.

## Export a CSV

1. Apply the date, activity type, search, and sort options you need.
2. Select the download icon.
3. Review the CSV to confirm it contains the expected filtered rows.
4. Store the file securely for accounting, tax, or compliance use.

<Callout type="info">
  The export contains the rows represented by the current filtered view. Change the filters before downloading if you
  need a different scope.
</Callout>

For an onchain action that does not appear as expected, keep its transaction hash and
compare it with the connected wallet's network activity.
