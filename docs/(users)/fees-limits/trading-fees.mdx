Trading fees vary by market and are applied automatically when an order fills. The order
preview shows the estimated amount before you sign.

## Current fee rate

Enter an outcome token ID to load the complete rate currently used for that market:

<TradingFeeLookup />

The displayed percentage is a rate parameter, not a flat percentage of the order
notional. The final fee depends on the execution price and filled quantity.

## Market and limit orders

- **Market orders** execute as taker orders and use the market's live fee schedule.
- **Limit orders** incur the applicable maker or taker fee when each fill occurs.
- A partially filled order can produce several fee entries, one for each fill.
- A maker rebate applies only when the site has explicitly configured one.

## Affiliate attribution

A valid referral does not change the fee paid by the trader. Eligible commission is
tracked separately using the site's current affiliate rate.

## Verify a fee

Check the order preview before signing and **Portfolio → History** after execution. The
live values shown by the site take precedence over examples in this guide.
